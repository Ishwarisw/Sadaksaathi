# SadakSaathi

Report a road hazard in 30 seconds.

## Problem
Potholes and broken roads cause thousands of accidents in India every year,
and complaints are slow and hard to file.

## What it does
- Take a photo of the hazard
- Capture GPS location
- Auto-write a ready-to-send complaint with a Google Maps link
- Community votes: still broken / fixed

## Run locally
Open the folder in VS Code and use the Live Server extension on index.html.

## Limits
Reports are saved in the browser only. Next step: a shared database.
